# 有赞商家后台操作手册（实测版）

基于 2026-10 的有赞微商城后台（zent 组件库）。界面可能改版，文中坐标基于 1454 宽的浏览器视口，仅供参考。优先在页面里执行 JS、按文字定位元素；需要按坐标点击时，先截图确认。下文的「执行 JS」「截图」「真实键入」「填文件」指你的浏览器自动化工具里对应的操作（见 SKILL.md 文末的「能力对照」）。

## 1. 通用技巧

- **React 受控输入框**：用脚本赋值（`el.value=...` + 派发 input 事件）有时只改了 DOM，没进表单状态（症状：预览不变、保存时提示「请输入库存」）。可靠写法是先用脚本聚焦并全选，再用**真实键盘输入**（如 Playwright `keyboard.type`、CDP `Input.insertText`，或浏览器工具的 type 动作）：
  ```js
  window.__f=i=>{const e=[...document.querySelectorAll('input:not([type=file]):not([type=hidden]), textarea')][i];e.scrollIntoView({block:'center'});e.focus();e.select();return e.placeholder};
  ```
  价格、运费输完被格式化成 `12.80`、`0.00`，就说明表单收到了。
- **按标签找字段**：编辑页和新建页的输入框顺序不一样，按标签找更稳：
  ```js
  const lab=[...document.querySelectorAll('[class*=label]')].find(l=>l.innerText.trim()==='商品卖点：');
  const g=lab.closest('[class*=control-group],[class*=form-control]')||lab.parentElement;
  const input=g.querySelector('input,textarea');
  ```
- **复选框用脚本点**：留言的「必填」等复选框，用坐标点击容易在布局变化后误点到旁边的「删除」。用 `[...document.querySelectorAll('input[type=checkbox]')].find(c=>c.closest('label')?.innerText.trim()==='必填')`，判断没勾再 `.click()`。
- **#hash 跳转不会重新加载**：`/v4/goods/edit#/id=A` 跳到 `#/id=B` 时，单页应用可能还停在 A 的表单上，接着操作会改错商品。每次换商品前先跳到别的页面（如商品列表），或者在动手前读一次商品名核对。
- **满意度调查浮层**会挡住列表右下角，先点它的 ×。
- 有赞部分按钮用 `window.open` 开新窗口（如个人中心的「编辑」）。新窗口可能不受你的自动化会话控制，可以先拦截，拿到地址后在当前标签页打开：
  ```js
  const o=window.open; window.__opened=[]; window.open=u=>{window.__opened.push(String(u));return null};
  /* 点击按钮 */ window.open=o; window.__opened
  ```

## 2. 素材库上传

所有图片入口（商品图、详情图、装修组件）都会先弹「我的图片」素材库：

1. 点左上「上传图片」标签切到上传表单（商品页大约在 (331,135)，个人中心组件里的位置不同，先截图）
2. 定位弹窗里「本地图片」对应的 `input[type=file]`，把本地文件填进去（Playwright `setInputFiles` / CDP `DOM.setFileInputFiles` / 浏览器工具的上传动作）。不要点它，点了会弹出系统文件选择框，自动化操作不了。
3. 点「确定」（商品页大约在 (1088,404)，装修页大约在 (1093,603)）

注意：
- **上传后会把这次传的所有图都插进当前字段**。只传当前商品需要的图，不要一次批量传。
- 已经传过的图，可以在素材库网格里点选再「确定」。素材库按上传时间倒序、每页 15 张，旧图会被挤到后面的页。
- 单张不超过 10MB；商品图最多 15 张，详情最多 50 张，装修组件里有的只能传 1 张。

## 3. 新建商品

入口：商品管理 → 发布商品（`/v4/goods/create`）。

1. 商品类型默认「实物商品」。
2. **更多功能**（右侧悬浮按钮）里把需要的字段加到表单：商品卖点、售后服务、开售时间、下单模式等。加过一次后，所有商品都会显示：
   ```js
   for (const w of ['商品卖点','售后服务','开售时间']){const c=[...document.querySelectorAll('.drawer-field-cell')].find(c=>c.innerText.trim()===w); c?.querySelector('.drawer-field-cell-icon_plus')?.click();}
   ```
3. 主图：上传后检查 `.app-image-list li.image-item` 的数量，多余的用 `li a.close-modal` 删掉。
4. 新建页的输入框下标（实测）：10 名称、11 卖点、12 价格、15 库存、22 统一邮费、32 开售时间里的「放入仓库」单选、33 限购复选框。
5. 配送：实物商品只有快递发货或到店自提，没有「无需物流」。需要的话就设统一邮费 0，并提醒用户订单要手动点「发货 → 无需物流」。
6. 售后服务：「7天无理由退货」「自动退款」默认不勾。自动退款开着的话，待发货订单 6 小时内买家可以直接退款，卖虚拟服务时要保持关闭。
7. 限购：勾「限制每人可购买数量」→ 选「终身限购」→ 填数量（真实键入）。
8. 留言：点「+添加字段」，把名称改成「App 账号手机号」之类，格式下拉选「手机号」，必填用脚本勾上。下拉选完后整行布局会变，「必填」和「删除」的位置都会挪动。
9. 商品详情：「快速添加 → 图片」→ 上传切好的详情图（按 -1/-2/-3 顺序一次传）。
10. 保存前用脚本核对：名称、卖点、价格、库存、运费、勾选项、留言名、详情图数（`上传图片(\d+)/50`）、错误提示（`[class*=error-desc]`）。
11. 点「保存并查看」→ 经常弹出「开启电子合同」→ 点「暂不需要」。**这个弹窗关不掉**（Esc、遮罩、隐藏的 close 都没用），只能二选一。
12. 跳转到 `tuicashier.youzan.com/...` 预览页才算保存成功。

## 4. 编辑已有商品

- 编辑地址：`https://www.youzan.com/v4/goods/edit#/id=<商品ID>`。ID 从商品列表行里「编辑」链接的 href 拿。
- 已上架和仓库中的商品分在列表不同的标签下：销售中在默认视图，仓库中用 `typeId=2`。
- **换主图**：`li.image-item a.close-modal` 全删 → 点「上传图片」→ 上传新图 → 确定。
- **换详情图**：`.quick-add-sort .sort-item .del` 逐个删，再按新建时的方法上传。
- **库存**：编辑页的库存是文字加铅笔图标，点铅笔弹出输入框 → 输入 → 确定 → 再保存商品。
- **类目**：「修改类目」或「选择商品类目」→ 弹窗上方可以搜关键词（`请输入类目或类目关键词`），或点「最近使用」→ 确定。有赞可能根据商品名自动套类目（如商品名里带「本」字被套成「笔记本/记事本」），上架后要逐个检查。会员服务类商品用过「生活服务 > 教育培训 > 智能教育」，类目参数都是选填。
- 编辑页的开售时间单选会显示当前状态（立即开售/放入仓库），保存前确认没被误改。

**弹窗挡住保存、表单又被误改的救法**（实测发生过）：用脚本把 `.zent-dialog-r-anchor` 设为 `display:none`（不要隐藏它的上层容器，那是整个应用），在表单里把内容补回来，再把弹窗显示回来，点「暂不需要」，会按当前表单内容保存。

## 5. 上架/下架

商品列表每行有「上架」「下架」链接，点一下立即生效、没有确认弹窗，会提示「上架成功」。用脚本按商品名定位后 `.click()` 最稳。用坐标点容易点到相邻的「…」菜单，因为列表右侧是固定列。点完到「销售中」标签核对。

## 6. 店铺主页（微页面编辑器）

- 地址：页面管理（`/v4/deco/decorate-list`）→ 主页行「编辑」→ `/v4/deco/decorate#/edit/<页面ID>`。
- 左侧点组件会添加到**当前选中组件的后面**（选中最后一个时就加到末尾）。调顺序用组件右侧的「↑」按钮；画布会跟着滚动，按钮位置基本不变。
- **商品组件只能选「已上架」的商品**。主页要展示的商品得先上架。
- 列表样式：大图模式、一行一个支持「按钮」类购买按钮，可以自定义文字（如「立即购买」）；一行三个只有图标或「不显示」。
- 排序：默认「智能排序」，改成「手动排序」后，缩略图拖拽很难模拟。想要指定顺序，就按顺序**一个一个**选商品（每次打开选择框只勾一个）。
- 选择框里勾选商品：
  ```js
  const d=[...document.querySelectorAll('div')].find(x=>x.innerText?.startsWith('选择可用商品'));
  const tr=[...d.querySelectorAll('tr')].find(r=>r.innerText.includes(关键词)); tr.querySelector('input[type=checkbox]').click();
  [...d.querySelectorAll('button')].find(b=>/^确\s*定$/.test(b.innerText.trim())).click();
  ```
- 删除组件：选中后点右侧垃圾桶，立即删除、没有确认。
- **存至草稿**：保存后编辑器常常重新加载成**线上版本**，顶部出现「该页面有一条草稿记录，可以还原草稿继续编辑」。要点「继续编辑」才会回到草稿。发布前一定先还原草稿，并核对内容。
- **不要点「预览」**：它会提示「预览会覆盖草稿内容」。如果误点了，在提示框里选「关闭」。
- 画布滚动容器是 `.preview-wrap`。

## 7. 个人中心

- 地址：`/v4/deco/usercenter-decorate`。**只有「立即发布」，没有草稿**。先在编辑器里改好，截图给用户确认，标签页保持打开不要离开，用户同意后再发布。
- 模块：
  - 个人信息：背景图 960×440、会员等级展示/隐藏。会员等级是有赞的店铺会员，跟 App 会员不是一回事，容易混淆，建议隐藏。
  - 个人资产：余额/积分/权益卡/优惠券/钱包可以逐项取消勾选，全部取消后整个模块不显示。
  - 广告位：710×200，轮播。
  - 我的订单：固定模块。
  - 必备工具：购物车、任务中心、分销员中心（可设「仅分销员可见」）、返现、赠品、收货地址、账号与安全、客服聊天等复选框。
  - 底部可以追加基础组件，如图片广告（宽 750）。
- 编辑器里的「不展示此组件」只是占位提示，买家看不到。
- 页面滚动用 `document.scrollingElement`。

## 8. 交易设置与底部导航

- 交易设置：`/v4/setting/team#trade` → 基础设置 → 「购物车：开启/关闭」→ 底部「保存」。关闭后买家只能单独购买结算，商品页底部只剩「立即购买」。后台商品编辑页的预览里不会体现这个变化。刷新后读单选状态核对。
- 底部导航：`/v4/deco/shopnav-config#bottom` → 导航卡片右上角垃圾桶删除 → 「保存」→ 提示「保存导航成功」。
- **这个页面一直挂着「离开前提醒」**，保存后依然在。离开或关闭标签页都会被拦住，脚本也去不掉。核对时另开一个标签页加载同一地址；旧标签页让用户自己关掉（Chrome 问「离开此网站？」时点「离开」）。如果你的工具能处理 beforeunload 对话框（如 Playwright 的 `page.on('dialog', d => d.accept())`），也可以自己确认离开。不要反复重试。

## 9. 截长图给用户看

编辑器画布一屏装不下时：

1. 找到滚动容器（主页是 `.preview-wrap`，个人中心是 `document.scrollingElement`），记下 `scrollHeight`。
2. 依次设 `scrollTop = 0, 视口高, 2×视口高…`，每次截取手机画布区域（只截画布所在的矩形，尽量用高 DPR 原尺寸，不要压缩成缩略图）。
3. 按 `scrollTop` 差值乘以截图倍率换算像素偏移，裁掉重叠部分，用 `scripts/render_tools.py` 的 `stitch_vertical` 竖向拼接，存到项目目录后交给用户。
